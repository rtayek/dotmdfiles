# LLM Output Principles: Role Over Label

## Core Rule
Prioritize functional and conceptual descriptions over volatile identifiers (such as specific file names, labels, or paths). Reference entities by their architectural role or responsibility to ensure documentation and code remain resilient to renaming and refactoring.

## Guidelines
1. **Decouple Concept from Identifier:** Avoid hardcoding concrete names across multiple artifacts. If a name changes, downstream notes shouldn't break.
2. **Localize Details:** Keep specific implementation details restricted to their immediate context rather than duplicating them across handoff files and docs.
3. **High Signal Density:** Focus on structural relationships and responsibilities to keep output concise and minimize visual clutter.
